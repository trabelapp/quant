# Archive

quantify.trading was shut down (legal/regulatory risk too high to run as a minor).
Everything that used to be live is kept here, untouched, in case the domain and
engine get reused for a different business later.

- `quantify_engine_main.py` — the full FastAPI app (scanner, accounts, payments,
  email sequences, admin tools) that used to be `main.py`.
- `static/` — the site's images/icons.

The live `main.py` at the repo root is now a blank placeholder page.
